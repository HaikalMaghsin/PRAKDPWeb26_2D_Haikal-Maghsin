## Hasil penggabungan

Halaman dan CSS merupakan kelanjutan versi gabungan [Jobsheet 3](../Jobsheet3/README.md), dengan penanda footer Jobsheet 4. Data, palet warna, dan halaman edit milik Haikal tetap tersedia.

Materi baru ada pada [wireframe dan user flow](docs/wireframe.md): aktor Tamu/Petugas, Login, Dashboard Petugas, Peminjaman, Pengembalian, dan Riwayat Peminjaman per anggota. Rancangan dari Pak Dimas dilengkapi panduan warna proyek Haikal, pemetaan halaman yang sudah ada, serta alur stok habis dan tunggakan.

## Cara menjalankan

Buka [index.html](index.html) di browser atau gunakan Live Server untuk melihat halaman responsif. Buka [docs/wireframe.md](docs/wireframe.md) melalui Markdown Preview di VS Code untuk membaca rancangan.

Login, otorisasi, dan transaksi masih berupa rancangan untuk jobsheet berikutnya. Form yang ada belum menyimpan data.
